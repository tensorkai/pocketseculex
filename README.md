The architecture of the PocketSeculex ecosystem is strictly divided into two synchronized experiences: the User and the Local Government Unit (LGU), which encompasses police and rescue teams. For the User, the hardware is no longer a complex wearable but a robust, bae-attachable module powered by a standard ESP32 microcontroller and a Quectel 5G/LTE cellular module. Stripped of physiological monitors like the pulse sensor, the device acts as a discrete, immediate lifeline. When a crisis occurs, the user simply engages the dual push-button manual trigger. Instantly, the hardware locks onto its GNSS coordinates and fires a secure telemetry payload—containing precise location data and the user's pre-registered profile—directly to the Supabase backend.

The moment that signal reaches the cloud, the system's artificial intelligence bridges the gap between the user in distress and the LGU dispatchers. The Next.js platform immediately routes the raw telemetry through the Groq API, leveraging the ultra-low-latency inference speed of the Qwen 3.8 27B model. In milliseconds, the AI evaluates the coordinates, user identity, and trigger timestamp to synthesize a highly structured, 911-style situational brief. This ensures that raw database entries are instantly transformed into a clear, actionable text assessment before human eyes even need to interpret the data.

On the receiving end, the LGU dashboard serves as a high-speed command center tailored specifically for emergency responders. Police and rescue teams monitor a high-contrast, real-time map that pinpoints the user's exact location, deliberately omitting variables like weather patterns or dynamic traffic to keep the interface purely focused on the target. To facilitate deployment, the system uses server-side Dijkstra and A\* algorithms to calculate the most direct geographical route to the distress signal. Paired with the Qwen-generated brief and a live-updating path that tracks the bag-attached device on the move, the LGU is equipped to respond instantly with complete situational awareness.
